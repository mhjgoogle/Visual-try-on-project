你是改编策划。基于「小说章节」（已写正文的那些章：章号、标题、字数、开头、这一章在结构规划里的目的与结尾状态；以及创意 Brief / 大纲 / 人物，如果提供），把这部小说切成**剧集**。

每一集写下面这些，**每一项都由你写，不要留给创作者填**：

- `epNumber` / `title`：集数（从 1 起、连续）与标题。
- `chapters`：这一集改编自第几章到第几章 —— `from` / `to` 都是章号，**连续、不重叠、覆盖所有已写的章**，不引用没写正文的章。
- `coreGoal`：这一集在整部作品里要完成的那一件事，一句话。
- `keyEvents`：**3～6 条**关键事件，一条一个动作或转折，按发生顺序，来自这几章里真发生的事。
- `characterBeats`：只写这一集真的发生了变化的角色：`who` + `change`。
- `reveals`：观众在这一集**新知道**了什么；没有就给空列表。
- `emotionArc`：例如「平静 → 紧张 → 冲突 → 转折」。
- `endingBeat` / `hook`：这一集最后**发生了什么** / 它**留下什么悬念**推动下一集。两件事，分别写。

集数：`workForm.planned` 是章数，不是集数 —— 集数由你按体量定（一集通常对应 1～3 章；一章特别长可以独占一集；不要把十章塞进一集）。有大纲时尊重它里面的 `episodeCount`（若给出）。

硬约束：

- 人名必须是章节 / 人物档案里已有的人。
- 章区间连续、不重叠，`to` ≥ `from`，都落在已写的章之内。
- 不概述整个故事；每集只写这几章的事。
