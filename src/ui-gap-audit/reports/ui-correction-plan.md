# UI Correction Plan — 要改什么、按什么顺序、哪些明确不做

**日期** 2026-08-16 · 依据：本目录 5 份审计报告 + 28 条 Gap
**状态**：计划，尚未实施。产品负责人可逐条否决。

排序依据（§26）：
**用户完不成任务 > 用户误解状态 > 已有能力被藏 > 流程低效 > 信息架构 > 视觉**。

## 零、明确不做（先划掉，省得反复讨论）

### 0.1 目标产品的商业外壳 —— 全部不做

| 项 | 为什么不做 |
| --- | --- |
| 积分 / 会员 / 限时折扣 / 积分超市 | 我们不是 SaaS 平台。我们的成本模型是**用户自己的 API key + 预算账本**（`budget/` 已实现 guard / reservation / ledger / FX），不是平台积分 |
| 创作者挑战赛 / 精选画布 / 社区展示 | 我们是本地单机工具，没有社区层 |
| 营销弹窗 / 活动倒计时 / 新人红包 | 同上 |
| 分享链接 / 多人协作 / 会话分享 | 不在当前范围，且涉及把用户创作内容外发 |

### 0.2 目标产品的结构选择 —— 不抄

| 项 | 为什么不做 |
| --- | --- |
| **把跨集的东西塞进画布** | LibTV 没有跨集层：《黑翼天使终章》的「天使资产」组只是**画布内**的一个分组，换一块画布就要再复制一份；「全季 48 集哪些做完了」它答不了。我们的 Episode/Scene/Shot + 作品设定 + 分集规划**就是那一层**，是我们相对它最实的优势 |
| **Agent 自主花钱**（「协作模式」开关） | ADR 明确禁止 Agent 定稿 / 付费。我们的「两步预检 + 人工确认报价」是对的，不退化 |
| **智能剪辑**（一句话剪成片） | 我们的时间线 5 轨 + 修剪/音量/淡入淡出 + 字幕 + 交付质检比它强得多。换成"一句话"是**退化** |
| 逐帧拉片（反解参考片） | 需要视频理解能力，超出当前授权。记 follow-up |
| 3D 导演台 / Blender 插件 | 需要 3D 引擎。记 follow-up |
| 复制别人的项目当模板 | 依赖社区层。**但「项目/流程模板」本身值得做**，见 Phase 3 |

### 0.3 我们已经比目标强的 —— KEEP，不要重构

创意 Brief → 故事大纲（批准门）→ 分集规划（确认→建实体）→ 本集剧本，**四层版本链** ·
作品设定（角色身份 + 状态覆盖 + 声音身份强制 + 参考图只引不复制）· 人物关系 · 世界观 ·
Episode→Scene→Shot 真实模型 · 分镜锁定为正式版本（Gateway 两步）·
对白/环境音/SFX/BGM 四层音频 · 时间线 5 轨 · 字幕（台词→字幕 / SRT）·
交付质检（ffprobe + ebur128 + blackdetect）· 原子版本化渲染（绝不覆盖）·
免费路线（复制 Prompt → 外部工具 → 导入，且记录真实溯源）

**这些一行都不要动。** 目标产品在这几项上要么没有，要么明显更弱。

## 六、执行纪律

- **每个 Phase 是一批，批内按 checkpoint 垂直切片**，每个 checkpoint 用户可见、可截图、可比较、可回滚（§37）。
- 每个 checkpoint 完成后**重新跑 `tools/capture_current.py`**，旧图归档到
  `screenshots/archive/YYYY-MM-DD/`，更新 manifest，生成 Before / After / Target 对比（§38）。
- 审查按 AGENTS.md 第 20 条分级：低=不审 / 中=1 轮 / 高=2 轮。
  Phase 1.3 与整个 Phase 3 是高风险。
- **Phase 0 与 Phase 1 不需要新 ADR**；Phase 3 每条开工前先落 ADR。
- 唯一必须先问产品负责人的仍然只有**真实付费**（CLAUDE.md）。
