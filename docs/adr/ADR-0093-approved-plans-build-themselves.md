# ADR-0093：他点「同意」，开发就自己开工

- 状态：Accepted
- 日期：2026-08-30
- 决策者：产品负责人 2026-08-30 —— 「现在这个架构下面。我能通过服务端命令后端运行开发
  和修改页面的要求吗。不需要我在这里对话。」技术形状由实施 Agent 依 AGENTS.md §1
  自行 Accept；**不涉付费 API**（走的是他已经付过的本地 Claude Code 订阅通道，
  与 ADR-0042 同一条），不动用户创作数据
- 关联：[REQ-006](../requirements/REQ-006-agent-can-do-what-the-creator-can-do.md) ·
  [ADR-0089](ADR-0089-conversational-agent-write-path.md)（决策 3b 落地回执 / 决策 8
  意见台账）· **扩展** [ADR-0042](ADR-0042-creative-agent-cli-integration.md)
  的无工具姿态（不取代：创意通道一条不改）

## 1. 背景：为什么今天做不到

`dev.request` 已经会真的起一轮 `claude-code`：它按他的话写出一份**修改方案**，
落成台账里的提案，他在卡片上答复同意 / 不要 / 要改。到此为止都通了。

断在最后一步：那一轮跑的是

```
claude -p --tools ""      # 一个工具都不给
cwd = 一个新建的空临时文件夹
```

**这是故意的**（ADR-0042）：提示词里内嵌了他写的剧本与他自己敲的意见，那是一条
天然的注入面；一个有工具、cwd 在仓库里的执行器，等于让「应用里的任意文本」变成
「一个能读写这个仓库的 Agent 的指令」。所以它写得出方案，写不了代码 ——
要把方案变成代码，仍然得他到开发终端来说一句。

他要的正是去掉这最后一句话。

## 2. 决策

### 决策 1：新开一条**能写**的执行器通道，与创意通道完全分开

`claude-code-dev`：有工具、cwd 是仓库。**创意能力一条都不走它** —— 分镜、Prompt、
关系整理这些仍然是 `claude-code`（无工具、空目录），ADR-0042 的姿态在它们身上
一字不改。两条通道在执行器表里就是两行，不靠调用点自觉。

### 决策 2：**只有他点「同意」才开工**，不是说句话就开工

能触发它的入口**只有一个**：台账里一条 `decision.verdict == "approved"` 的提案。
提案的正文是上一轮开发写的、**他读过并点了同意**的那份方案。

这就是那道注入控制在新通道上的等价物：进入能写通道的文本，必须先经过一次
**人的阅读与同意**。他没看过的东西，一个字也进不来。「不要」与「可以但要改」
都不开工 —— 后者回到写方案那一轮（他的修改意见是新需求，不是开工令）。

### 决策 3：树是脏的就**拒绝开工并说明**，不排队等着覆盖

开工前检查 `git status`。有未提交的改动（很可能是另一个 Agent 正在做的事，
AGENTS.md 第 16 条），就把提案标成「暂时开不了工：工作区有未提交的改动」
并**保留待办**，不动任何文件。同一时刻只允许一轮在跑。

### 决策 4：结果**写回他看得见的地方**

提案卡片上的状态就是他的进度条：

    已同意 → 开发正在改（第 N 分钟）→ 改好了（提交 abc1234）
                                    └→ 没能改成：<原因原话>

失败必须说人话的原因（ADR-0089 决策 6 的同一条规矩：做不到就说做不到，
不许假装做了）。

### 决策 5：护栏靠既有的三样，不新发明

1. **提交闸门**：那一轮和人一样受 `.claude/hooks` 的约束，测试不过就提交不了；
2. **Git 历史**：改错了是 `revert`，不是灾难；
3. **分支**：在当前分支上做，不碰 main 的直推。

## 3. 代价（已接受，且当面说过）

- **会自动花掉他的 Claude 用量**，而且是在他没盯着的时候。这不是新的付费授权
  （同一条本地订阅通道，ADR-0042 已授权），但**花费节奏变了** —— 以前每一轮都由
  他在终端里发起，现在他点一次「同意」就会有一轮跑起来。这一条当面告诉过他。
- 一个有工具的 Agent 在仓库里跑，爆炸半径真实存在。控制是决策 2 的人工同意 +
  决策 3 的干净树 + 决策 5 的三道护栏，**不是**「模型应该不会乱来」。
- 它可能改错。兜底是他再说一句「不对」—— 那正是他自己定的路径
  （2026-08-24：「用起来不满意就再改啊没有什么更好办的方法」）。

## 4. 不做什么

- 不给创意通道开工具（ADR-0042 的姿态在那边一字不动）。
- 不做「自动决定要不要开工」的判断：**同意是他给的**，不是模型推断的。
- 不在他没看过的文本上开工。
- 不新增任何要他离开对话去手动操作的步骤（第 1 节那条禁令）：打开 MOTV 就够了。
