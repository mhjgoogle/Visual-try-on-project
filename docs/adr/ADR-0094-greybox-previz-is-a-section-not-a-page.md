# ADR-0094：3D 白膜导演台是「分镜设计」的一个分区，用浏览器自带的 WebGL

- 关联：[ADR-0066](ADR-0066-product-refactor-fixed-ia-review-layers-and-system-contract.md)

## 1. 背景

白膜（grey-box previz）是分镜与实拍/生成之间那一步：**先不管长相，只把走位、机位、
节奏摆对**。他要的是能在剧集制作里做出这样一段视频。

三件事约束了形状：

1. **十一页是闭集**（ADR-0066 决策 10）。加第十二页需要充分理由，而白膜并不是一个
   新的工作阶段 —— 它就是分镜在立体空间里的样子。
2. **这个仓库零第三方依赖**，且 CSP 只允许自身来源：Three.js 这类库既不能装也不能
   从 CDN 取。
3. **不许假的 AI / 假的成品**（ADR-0041 一脉）：白膜就是白膜，不得渲染成看起来像
   成片的东西，也不得声称它是「预览的最终画面」。

## 2. 决策

### 决策 1：它是「分镜设计」的第三个分区，不是第十二页

`storyboard: ["scenes", "shots", "blocking"]`。场景 → 分镜 → **3D 导演台**：
同一页里从「有哪些场景」到「这一镜怎么拍」，白膜是最后那一步的立体表达。
闭集守卫（`PAGES.length === 11`）一字不动。

### 决策 2：用浏览器自带的 WebGL 手写一个极小渲染器，不引任何库

`src/ui/blockgl.js`：一个只画**盒子与地面网格**的渲染器，约 200 行，
顶点/片元着色器内联。它只需要做三件事 —— 摆几个方块、给一台有焦距的相机、
打一盏方向光。库能给的其余一切（材质、贴图、后期、GLTF）在白膜里都是噪音。

**代价**：没有阴影柔化、没有抗锯齿以外的画质手段、没有模型导入。这正是白膜该有的
样子；需要长相的时候走的是镜头制作那条链，不是这里。

### 决策 3：数据是「机位关键帧 + 演员站位」，与镜头绑定

一镜一份 blocking：地面尺寸、演员（名字 + 身高 + 起止站位）、道具方块、
相机在起止两个时刻的位置/朝向/焦距、时长。中间全部线性插值 ——
**先把「谁从哪走到哪、镜头怎么跟」说清楚**，曲线与缓动留给以后。

写路径与其它创作数据同一条纪律：纯函数、可撤销、日常编辑不产生版本
（[ADR-0089](ADR-0089-conversational-agent-write-path.md) 决策 3 的同一条规矩）。

### 决策 4：产出的白膜视频是**资产**，走既有登记

录制用浏览器自带的 `canvas.captureStream()` + `MediaRecorder`，产物经既有的资产
登记路径落地，`kind` 为 `previz`，绑到那一镜。于是它天然获得版本链、来源记录与
「资产库」里的位置，不需要为白膜再造一套存储。

**浏览器不支持录制时说出来**（fail-closed）：给出「你的浏览器不支持录制」这句话，
而不是给一个按下去没反应的按钮。

### 决策 5：Agent 能改它，和创作者走同一组函数

`blocking.*` 动作进 `convactions` 的动作表（REQ-006 判据 1：**创作者能操作的，
Agent 都能操作**）。「把镜头拉远一点」「让林照从门口走到吧台」这类话因此能落成真改动，
而不是一段建议文字。

## 3. 不做什么

- 不引入 Three.js 或任何 3D 库（决策 2）。
- 不做模型导入 / 骨骼 / 动作捕捉：白膜里演员就是一个有身高的方块。
- 不把白膜与成片混为一谈：它的 `kind` 是 `previz`，在资产库里就是这个身份。
- 不新增一级页面（决策 1）。
