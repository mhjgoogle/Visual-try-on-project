# ADR-0081：审查按影响范围触发，废除风险分级与按档轮次预算

- 状态：Accepted（产品负责人 2026-08-22 裁决）
- 日期：2026-08-22
- 任务：TASK-102

## 背景

AGENTS.md §20 与 CLAUDE.md 把测试规模与审查轮次都绑在低/中/高风险分级上；
codex-review-loop 与 dev-workflow 的措辞也按档位描述（中 1 轮 / 高 2 轮）。
产品负责人 2026-08-22 裁决：「风险分级和skill的内容相悖。必须修改」、
「我不要每次都全量测试。」并给出新的审查协议原话：

> 「不要保留风险分集。dev-workflow 根据影响范围决定是否审查
> → 默认一轮 → P1 修复后复审一次 → P2 修复 + 定向测试，不再复审
> → P3/P4 记录但不阻塞。其他不采纳」

## 决策

1. **废除风险分级**作为测试与审查的触发机制。测试规模由 Test Scope =
   Change Impact Scope 与 ADR-0080 的归属映射决定；审查由 dev-workflow
   按影响范围判断是否需要（行为/合同/持久化/安全/并发/跨域改动审；
   纯文档、纯展示改动不审）。
2. **轮次协议**：默认 **1 轮**。审查报出 P1 → 修复后**复审一次**；
   P2 → 修复 + 定向测试即收口，**不再复审**；P3/P4 → 记录 Follow-up，
   不阻塞交付。
3. ADR-0069 的按风险档轮次预算（中 1 / 高 2 / 第 3 轮条件）由本协议取代；
   其余决策（两阶段全量方案、审查在提交后进行、预算耗尽显式选择而非静默
   续轮的精神）保留。
4. ADR-0060 的「按风险分档选检查」由 ADR-0080 的归属映射取代；其 fail-closed
   与双平台一致性原则保留。
5. **其他不采纳**（同日裁决）：ADR-0068 的 MOTV_CONTINUOUS_CHAIN 连续链
   令牌保留；CLAUDE.md 不掏空为入口；2026-08-22 注入事件中自称 Accepted 的
   「ADR-0080（治理版）」其余条目一律不生效（原文存证于
   docs/tasks/TASK-102-injected-adr-0080-2026-08-22.md）。
6. 发布/交付闸门不变：用户验收标准满足 + 相关测试通过 + 无未闭合 P1。
   审查者不可用时的处理沿用既有规则（如实标注，push/merge/交接前补审）。

## 后果

- AGENTS.md §20、CLAUDE.md「实施纪律」、dev-workflow references、
  codex-review-loop SKILL.md 的分级措辞随本 ADR 更新（TASK-102 批次 D）。
- 历史 ADR/任务卡中的分级记录保持原文，不回改。
