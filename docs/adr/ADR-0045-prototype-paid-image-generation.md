# ADR-0045: motv 原型的窄授权付费图片生成（MiniMax image-01）

- Status: Accepted
- Date: 2026-08-07
- 关联: ADR-0006/0009（MiniMax 视频窄授权先例）、ADR-0041（付费视频 Gateway
  写路径）、ADR-0042/0043/0044（原型草稿域模式）、ADR-0038（Proposed 核心
  多媒体 Provider 合同——本决策不预判、不触碰）

## 背景

motv 原型的资产设定图目前只有免费手工路（Gemini 网页生成 → 上传）。用户
明确要求界面同时提供"付费自动"与"手工上传"两种选择（视频已具备：手工 +
ADR-0041 付费 Gateway）。图片的付费自动此前无任何授权。

## 决策

1. **窄授权**：批准 motv mockup 后端以 `WFM1_MINIMAX_API_KEY`（与视频同一
   凭据）调用 MiniMax `image-01` 文生图 API，单价按官方目录 **$0.0035/张**。
   仅此模型、仅此用途（原型草稿资产设定图）、仅在服务器以 `--enable-paid`
   ＋ `AI_VIDEO_WORKFLOW_ENABLE_PAID_COMMANDS=1` 启动时可用（与视频付费同
   开关，缺省关闭）。
2. **每张人工确认**：UI 在每次生成前弹出明示单价的确认；无确认不调用。
   后端要求请求显式携带 `confirm_usd` 字段且与目录价一致，防止 UI 漂移后
   静默扣费。
3. **本地支出留痕**：每次成功调用追加一行 JSONL 到
   `data/paid-image-log.jsonl`（时间、槽位、prompt 摘要、金额），gitignored；
   这是原型级透明记录，不冒充核心预算台账。
4. **草稿域**：产物写入 `data/uploads/<project>/<slug>`（与手工上传同槽位，
   magic 校验后落盘），不写核心文件；正式 S4 资产的付费图片生成仍等
   ADR-0038 合同族。
5. **fail-closed**：key/开关缺失 → 403/503；prompt 超限（1500 字符）→ 400；
   API 错误/超时/返回非图片 → 5xx 并附错误类别；绝不伪造成功。

## 后果

- 图片步骤获得"手工（免费）+ 自动（付费，每张 $0.0035 确认制）"双路线；
- 原型付费面扩大到图片，但受同一部署开关、同一凭据、每张确认与本地留痕
  约束；月度上限继续由 MiniMax 控制台侧预算兜底；
- 核心工作流的图片 Provider 抽象与预算台账整合仍由 ADR-0038 决定，届时本
  路线可平移或废弃。
