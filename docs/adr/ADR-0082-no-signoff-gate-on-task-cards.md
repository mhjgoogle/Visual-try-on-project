# ADR-0082：任务卡收口不设「产品签字」闸；状态拆成两个独立事实

- 状态：Accepted
- 日期：2026-08-23
- 决策者：产品负责人（本条为其明确裁定）
- 关联：[AGENTS.md](../../AGENTS.md) §1（决策判据）、§18（决策入库）、§20（发布闸门）·
  [ADR-0081](ADR-0081-review-by-impact-scope.md)（审查不阻塞交付，同一族）·
  [TASK-087](../tasks/TASK-087-followup-ledger.md)（欠账总账）

## 1. 背景（改之前的状态，不是本 ADR 的结论）

`docs/implementation_plan.md` 写着「**需要产品签字才能收口**」，三份里程碑 runbook
里还有字面签字栏：

```
- [ ] **最终产品基线：PASS / 需返工（圈选）**，签字：________ 日期：________
```

于是任务卡出现了第三种状态：**实现做完了、测试绿了、但卡上仍写「进行中」**，
因为没人签字。

## 2. 这条规则的实测代价（2026-08-23 复查量出来的）

九张卡的代码 **2026-08-13** 进基线（`ae0a54a`），状态行**十天没动**。这十天里它
产生的不是谨慎，是**信息错误**：

| 现象 | 后果 |
| --- | --- |
| TASK-051 / 051A / 051B 标「待视觉验收」 | 它们要验的界面早被 ADR-0066 的固定十一页取代，**验收对象不存在** —— 在等一个不可能到来的签字 |
| TASK-052 整张标「待开始」 | 四条里 2.1 / 2.3 早已做完；这个错标签把另外**两条真缺陷盖了十天**（审查门会让没被审查的文件拿到 `pass`；`_discard_body` 只有字节上界没有时间上界）。没人会去翻一张「还没开始」的卡 |
| TASK-087 没能防住重复发现 | 那张卡存在的唯一理由就是防这个。它失效是因为**欠账不在它里面，在九个「等签字」的标签背后** |

## 3. 决策

### 决策 1：**任务卡收口不设产品签字闸**

判据用 AGENTS.md §1 已有的那一条：**错了能不能重来**。
改一个任务卡的状态是**纯可逆**的（写错就改回来），因此按本项目自己的规矩就该直接
做。保留人工闸的只有两类：**merge 到 main**（一次交给所有拉取者）与**付费**。
任务卡状态两类都不是。

产品负责人 2026-08-23 原话（对「没有签字闸就可能出现卡上写完成、你用起来不满意」
这一代价的回应）：

> 「用起来不满意就再改啊没有什么更好办的方法。」

### 决策 2：状态是**两个独立事实**，不是一个词

一张卡的状态必须分开写这两件，不得混成「进行中」：

1. **实现是否完成** —— Agent **可以**自己判定，且必须给代码级证据
   （文件、迁移函数、CI job、schema 版本这类能被复核的东西）。
2. **哪些验收项还没有在真实项目上被人看过** —— 如实逐条列出，
   **这是信息，不是闸门**。

**理由**：旧措辞把「实现没做」和「没人看过」压成同一个词「进行中」，读的人无法
区分，于是每次都要重新推导一遍。分开写严格更有信息量，且两者都可被复核。

### 决策 3：里程碑 PASS 仍归用户，但**形式必须是一句话**

TASK-033 / 037 / 040 这类**里程碑**是对整个产品的声明，保留由用户判定。
但 runbook 里 `签字：________ 日期：________` 的表格形态**取消** —— 它正是
AGENTS.md §1「不得新增要用户离开对话手动操作的规则」所禁的那种东西：

> 要用户拍板的事，**必须能用一句话完成**。

一句「这个可以了」即为里程碑 PASS，记录进 runbook 与任务卡，注明日期与原话。

### 决策 4：不满意的处理路径就是**再改**

不设签字闸的代价是「卡上写着实现完成、用起来却不满意」。本 ADR **接受**这个代价：
那种情况在有签字闸时同样会发生，而且当时还额外附带「卡片长期挂着假状态」的噪音。
真实的兜底一直都在，而且更快 —— 用的时候说一句不对，然后改。

## 4. 后果

- **好的**：任务卡状态重新变得可信；欠账回到 TASK-087 一处可见；不再堆积「等用户」
  的队列（用户在这个队列上无法批量行动，因为它要求逐条走几十项验收清单，
  而产品负责人明确说过他的决策输入点是「看到最终结果有问题之后」）。
- **要接受的**：卡片标「实现完成」不等于「产品令人满意」。**这两件事本来就不是
  一回事**，本 ADR 只是停止用一个状态词假装它们是。
- **不变的**：AGENTS.md §20 的发布闸门原样有效 ——
  **用户验收标准满足 + 相关测试通过 + 无未闭合 P1**。本 ADR 不放宽它，
  只是不再额外要求一个签字动作。
