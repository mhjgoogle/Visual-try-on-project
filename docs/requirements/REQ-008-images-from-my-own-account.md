# REQ-008：用我自己的账号自动出图，不要按次计费的 API

- 状态：CONFIRMED
- 来源：产品负责人 2026-09-05
- 版本：**v2（2026-09-05）· supersedes v1** —— 判据 2 的措辞从「用我自己的账号」
  收敛成「**不产生按次账单**」。改的原因是 v1 那句话把**手段**写进了判据：
  当天实测发现 Gemini 免费档对出图的配额是 0（三个模型全部 429 `limit: 0`），
  「用我自己的账号且不花钱」这条路**在事实上不存在**。而他真正要的从来是
  「别再卡住 + 不要按次计费」（原话见下），所以判据回到那件事本身。
  **判据 1、3–6 一字未改**；v1 全文保留在下方，不篡改。
- 相关 Change：[TASK-139](../tasks/active/TASK-139-images-from-my-own-account.md)
- 相关 ADR：[ADR-0100](../adr/ADR-0100-account-quota-is-not-a-paid-gate.md)
  （账号额度不走付费闸；判据是会不会产生按次账单）。
  它**不推翻** [ADR-0045](../adr/ADR-0045-prototype-paid-image-generation.md)
  的窄授权付费图片路 —— 两条路并存，付费那条继续锁在闸后面

## 他说的原话

> 「等 TASK-041 的付费写入方这一块。能不能想办法不要用付费 API 的方式。
> 而是使用我现有的生成 API 的 account 来自动获取图片呢。不然就一直卡在这一步不太好。」

追问「是哪一家的账号」时：

> 「我用的是网页版的 gemini 或者 gpt 的账户。codex 也可以用。」

## 他真正要的是什么

不是「省钱」，是**别再卡住**。今天图片只有两条路：手工（把 prompt 复制到网页版
Gemini，生成完再传回来）和付费自动（[ADR-0045](../adr/ADR-0045-prototype-paid-image-generation.md)
的 MiniMax image-01，每张 $0.0035，每次都要他确认一次金额）。第二条被
AGENTS.md §1「花钱是唯一必须问的那件事」锁着，于是整条自动路一直停在那儿。

他要的是**第三条**：用他已经有的账号额度自动出图，因此**不需要那道闸**。

## 判据（v2）

> **判据 2 · 不产生按次账单，因此不出现确认金额那道闸。**
> 走哪一家不重要，重要的是**这一次调用不会产生一笔按次账单**；界面上因此
> **不得**出现「这次 ≈$X，确认吗」。**手段不写进判据** —— v1 把它写成「用我自己的
> 账号」，而那条路当天就被实测证伪了，判据不该跟着一个具体手段一起失效。
>
> 2026-09-05 实测闭合：默认来源 Pollinations（无账号、无 key、无账单），
> 真实端到端 HTTP 200 / 2.9s / 39KB JPEG，落成 `hero_v1.jpg`，响应无 `usd` 字段。

**以下为 v1 原文，一字未改（判据 1、3–6 仍然有效；判据 2 已被上面那条取代）：**

1. **一键出图。** 需要一张设定图时，界面上点一下就生成，**不必**把 prompt 复制到
   网页版、等它出图、再把文件传回来。
2. **不产生按次账单，因此不出现确认金额那道闸。** 这条路走的是他账号里的额度；
   界面上**不得**出现「这次 ≈$X，确认吗」，因为那句话在这条路上是假的。
3. **凭据只粘一次，粘在界面里。** 不得要求他去改环境变量、加启动参数或编辑配置文件
   （AGENTS.md §1：「不要加什么自己改不了自己限制的设置」）。粘完立即可用，不用重启。
4. **额度用完就说额度用完。** 不得静默改走要花钱的那条路，也不得把「今天的免费额度
   到顶了」显示成一个笼统的「生成失败」。
5. **失败不重复消耗。** 超时、中断、重复点击都不得让同一个意图消耗两次额度；
   不确定是否已经消耗时，如实说不确定，**不自动重试**。
6. **产物和手工上传落在同一处。** 生成出来的图进的是他手工上传时的同一个槽位、
   同样版本化（不覆盖旧版），所以他看到的东西是一样的，不用学第二套规矩。

## 明确不在本需求内

- **不接 ChatGPT / OpenAI 的图片接口**：那边没有免费额度，`gpt-image-1` 按张计费，
  接上去等于退回他不要的那条路。
- **不爬网页版**（Playwright 驱动他登录的浏览器）：违反那两家的使用条款、页面一改就碎、
  还要一直有个登录着的浏览器被看着。而且没必要 —— 同一个 Google 账号就能拿到免费额度的 key。
- **不动视频**。视频的付费窄授权（ADR-0006 / ADR-0009 / ADR-0041）一个字不改。
- **不删也不改付费图片那条路**（ADR-0045）。它继续存在、继续锁在付费闸后面。
