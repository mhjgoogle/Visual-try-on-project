# REQ-005：主页可以把项目从列表里删除（文件他自己删）

- 状态：CONFIRMED
- 相关 Change：TASK-110

## v1 — CONFIRMED（2026-08-27）

- 来源：产品负责人 2026-08-27 —— 「主页项目需要可以选择删除。现在没有这个功能。」
  紧接着划定边界：「删除前端。后端的文件留下就好了啊。」「后端的文件我可以手动删除。」

- 用户真正需要什么：主页上那张项目卡片能被**去掉**，而且**只**去掉界面上的那条 ——
  磁盘上的项目文件夹留着，他自己决定什么时候清。他已经吃过一次相反方向的亏：
  他把 `照见未明` 的文件夹删了，卡片却一直在（账户级注册表还记着），于是问
  「我明明已经删除了为什么一直出现」。所以这件事必须能**在界面里了结**。

- 为什么：现在完全没有删除路径（`server.py` 无项目删除端点，`services/projects.js`
  只有增改）。唯一办法是去文件系统里动手，而那恰好制造了界面与磁盘不一致的状态。

- 验收判据（产品视角，非测试清单）：
  1. 主页每张项目卡片上都能发起删除；
  2. 删除**只动列表**，磁盘上的项目文件夹一个字节都不动；界面必须把这件事说明白
     （否则「删了怎么还占着盘」会变成下一个疑问）；
  3. 应用**不提供**任何删除他文件的按钮 —— 文件由他手动处理；
  4. 正在打开的项目不能就地删除（否则界面在对着一个已不在列表里的项目工作）；
  5. 删除之后列表立刻反映现实，不需要刷新或重启；
  6. 失败要说明原因，不能静默什么都没发生。
