## 一条贯穿的方法论

四条线是同一个根因的四个面：**屏幕上有的东西，Agent 的世界观里没有。**
`CA §6` 那条硬约束（动了页面就必须同改事实 / 页面地图 / 动作表）就是从这里来的，
`motv_doctor.py` 是把它从「记得住」变成「查得出」。

**一个喊狼的体检比没有体检更糟** —— 所以体检自己喊的三次狼当场全修了，各留一条测试。
