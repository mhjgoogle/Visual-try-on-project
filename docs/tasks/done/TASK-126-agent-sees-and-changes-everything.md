## 一条贯穿的方法论

四条线是同一个根因的四个面：**屏幕上有的东西，Agent 的世界观里没有。**
`CA §6` 那条硬约束（动了页面就必须同改事实 / 页面地图 / 动作表）就是从这里来的，
`motv_doctor.py` 是把它从「记得住」变成「查得出」。

**一个喊狼的体检比没有体检更糟** —— 所以体检自己喊的三次狼当场全修了，各留一条测试。

### 记录在案的残留局限

**文字完全一样的段落之间，文本里没有信息能把它们区分开。** 这一类连审四轮，
每轮都能构造出新反例。既定处置：数量不变 → LCS 保序；数量变少 → 整组不锚，
引用变 `§?`；数量变多 → 保序，前面的保住 id。

最后一条是**取舍不是正确**：`[A,A]` → `[A,A,A]` 且实际插在最前面时，原指向第一段
的引用会指到新插入那段上。反向处置的代价更大（复制一段会让原段丢 id）。
由 `storywork.test.mjs` 的「同文段落的身份：三种形状的既定处置」钉住。
