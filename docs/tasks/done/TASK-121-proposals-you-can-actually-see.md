## 第 2 条修了两次 —— 第一次我自己犯了要防的那个错

第一版把卡片画进 `.st-dir-flow` 的**顶端**。测试断言「DOM 里有 `.pp-card`」→ 绿。
真机截图一看：那根流有 **13993px** 高、视图停在底部，卡片落在他视线**上方 13217px** ——
DOM 里有、屏幕上没有。我上一轮修的「保持在最新对话」还把视图钉得更靠下，等于亲手把方案
推得更远。他第二次说「我根本没看到开发的提案」。

**「渲染了」不等于「看得见」**，和「测试通过」不等于「守住了那件事」是同一种错。
现在卡片钉在标题栏下面（`.st-dir-props`，`flex: none`，自己滚自己的），并且以后动界面
**必须看截图 + 断言元素在可视区内**，不能只断言它存在。
