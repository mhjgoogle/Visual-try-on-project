# TASK-070：初始人物从故事大纲的「主要角色概念」获取

- 状态：**已验收**（产品负责人 2026-08-13 随 ADR-0066 批准一并收口）
- 实施基线：`ae0a54a`
- **后续归属**：从大纲播种 Cast 由
  [ADR-0066](../adr/ADR-0066-product-refactor-fixed-ia-review-layers-and-system-contract.md)
  的「② 故事大纲 → ③ 作品设定」链路**原样继承**，无替代、无撤销。
- 负责 Agent：Claude Code（单一实施 Agent）
- 产品要求（2026-08-13）：「人物不是应该从剧本拆解。应该要从主要角色概念这边初始自动获取」
  「当然剧本细化之后也可以通过剧本分析人物。但是初始的时候是从故事大纲获取的」

## 0. 它解决的是一个真实的顺序矛盾

创作主线是：**创意 → 故事大纲 → 人物 / 世界观 → 分集规划 → 本集剧本**。

但在此之前，人物只有两条来路：手工一个个加，或者**剧本拆解**（M8）——而剧本在主线里
是**更靠后**的一步。于是「人物设定」这一格，在它所依赖的东西出现之前根本填不满。

故事大纲本来就携带 `outline.characterConcepts`（主要角色概念，界面上一直以 chip 显示），
只是从来没有人把它变成人物。

## 1. 两条路并存，不是二选一

| 时机 | 来源 |
| --- | --- |
| **初始** | 故事大纲的主要角色概念 → 播种成人物（本卡） |
| **剧本细化之后** | 剧本拆解（M8）继续补充与细化（**原样保留，未改动**） |

## 2. 为什么是提案而不是自动写入

`storydoc.js` 顶部写着 M9 规则 8：**大纲永不写入 Production Bible 实体**。这条规则的用意
是「大纲不得静默改写 canon」，而不是「人物不能从大纲来」。

因此播种做成**逐条确认**：`characterSeedsFromConcepts` 只做**推导**（纯函数，不写任何
东西），创建发生在创作者按下「创建」时。**大纲仍然不会自己写 canon，是人在写。**

## 3. 名字是猜的，所以必须让人看见

概念是自由文本（「林晚 —— 夜班调酒师，不肯交出录音」）。`splitCharacterConcept` 按
`—— / ： / : / - / 、 / ，`等分隔符切成「名字 + 身份」，**但这是一个猜测**：

- 概念**原样**显示在行里；
- 名字预填进一个**可编辑输入框**；
- 创建时用的是**创作者确认后的那个值**，不是启发式切分的结果。

静默地用启发式给角色命名，正是本仓库一贯拒绝的事；把猜测摆出来让人确认，是另一回事。

## 4. 交付

| 层 | 内容 |
| --- | --- |
| 文档域 `workflow/bibledoc.js` | `splitCharacterConcept` / `characterSeedsFromConcepts`（纯推导，按名字与已有人物 join，重复与空白丢弃） |
| 控制器 `src/app.js` | `ctx.bible.conceptSeeds`（读，带大纲版本与是否已批准）/ `ctx.bible.seedCharacter`（写一条，概念余文进「身份」） |
| 界面 `src/ui/biblews.js` | 正式角色页的播种面板；只在**有概念且尚未创建**时出现 |
| 样式 | `.seedbox` / `.seedrow`（概念过长时截断，不挤走可编辑的名字框） |
| 测试 | `tests/bible.test.mjs` +4 项（切分 / join / 不写入 / 渲染） |

## 5. 如实说明：浏览器里的「创建」这一步没跑通

两个真实项目（夜班沉默 / 照见未明rev2）的已批准大纲 `characterConcepts` **都是空的**，
所以面板正确地什么都不显示（这一点已在真实项目上验收）。

**没有验到的**是浏览器里真实点一次「创建」。播种本身由 4 组单元测试覆盖（含渲染层：
概念原样、名字可编辑、已有的不重复提供、无概念时不出面板）。等哪次 AI 生成的大纲带上
角色概念，这一步就能在真实数据上点通。

`characterConcepts` 目前**只能由 AI 大纲提案产生**（`OUTLINE_FIELDS` 不含它，所以手工
编辑大纲时填不了）。要让它可手填，是另一件事，本卡未做。

## 6. 明确不做

自动创建（必须逐条确认）；从概念推断外貌 / 服装 / 声音（概念里没有的东西不编）；
改动剧本拆解那条路；场景地的同类播种（世界观的 `characterConcepts` 对应物不存在）。
