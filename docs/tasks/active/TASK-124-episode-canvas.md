## 改成什么

**制作画布**（`board` 这一页的新内容，**不是新页面**），一屏三样：

1. **一条流水线** —— 剧本 → 设定同步 → 分镜 → 画面 → 视频 → 音频 → 剪辑 → 成片，
   每段带数（`3 / 3`、`1 / 3`）。数据来自既有的 `productionPlan`，不另算一份。
2. **一排镜头卡** —— 一镜一张：缩略图、走到哪（草图 / 白膜 / 关键帧 / 视频 / 审核）、
   卡住的原因、**一个**主按钮「下一步：…」。点它 = 选中这一镜 + 跳到那一页。
3. **一句下一步** —— 整集此刻最该做的那件事（`plan.next`，既有模型）。

左栏收成一行「制作画布」；停在别的页时那一行也画出来，否则左栏什么都不高亮。
原来的五页 + 3D 导演台收在画布底部的「全部工作区」里 —— **一个没删**。

结果：**这一屏 32 个按钮**（原来六页合计 110）。

## 两处「看着对、其实错」的地方，改前抓到了

- **步骤标签**：第一版把 `storyboard` 叫「分镜」，于是每张卡都显示「分镜 · 未开始」——
  而那三个镜头明明就在屏幕上。它其实是「分镜**草图**」这张资产做没做，与「有没有这
  一镜」是两回事。改用领域自己的名字（`STAGE_LABEL`），画布与工作区不会各说各话。
- **面包屑**「EP01 EP01 迷雾入城」：`title` 在真项目里已经带着集号，不能再前缀一次。

## 守卫

- 「⑨ 粗剪审片 REACHABLE」那条守卫是「有渲染器、有绑定、却没有任何入口」那次事故留下
  的。它的意图**不是「左栏里必须有」，而是「必须能进得去」** —— 所以现在它去检查
  画布的「全部工作区」里六个入口一个不少。
- 新增：左栏默认只画制作画布那一行；停在某一页时那一行要可见且恰好一个高亮。
