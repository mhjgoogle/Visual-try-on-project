## 1. 目标

把功能已经正确、但视觉「像后台管理面板」的 motv 制作视图，收敛成一个
**专业 AI 短剧制作工作室**。

验收主判据（用户给出）：

> 使用者应该感觉自己在**导演和制作一部 AI 短剧**，而不是在操作一个后台
> 管理面板、或者在配置一张 DAG。

## 2. 严格边界（本任务不做的事）

本检查点**只重建表现层**：

- 不新增产品域；
- 不重新设计持久化（画布 schema 仍为 v9，无迁移）；
- 不改变 Shot / Asset / Generation / Timeline 语义；
- 不新增 Provider；
- 不把 UI 状态写进生产域（模块选择、抽屉开合、变体页签、编辑开关全部是
  shell 上的 transient 状态）；
- 不复制第二份领域数据——所有界面仍只经 `ctx.*` 控制器读写既有文档。

**数据与行为保留，表现按需重建。**

## 4. 关键设计决策

1. **资产库升为顶层模式**。`存储` 离开左栏，并入顶栏「资产」——它就是
   规格 §11 描述的媒体浏览器（预览 / 用量 / 版本 / 存储状态 / 归档 / 移除
   本地副本 / 永久删除）。左栏因此只表达「项目」与「当前剧集」两个层级。
   受影响的单测已同步更新（`tests/workspaces.test.mjs` 的 NAV 用例）。
2. **生成入口移入 AI 导演**。M10 的 Prompt 编译 + 复制/打开/导入入口从分镜
   中栏迁到右栏 AI 导演（规格 §3），并抽出 `src/ui/genentry.js` 供
   分镜 / 画面 / 视频 复用。**行为不变**：intent 仍在复制或打开入口时捕获，
   只有走过入口的导入才记录真实 Generation 溯源；未走入口的导入仍是普通上传；
   API 自动生成仍是诚实的「未来」注记，不是假按钮。
3. **镜头编辑表单降为次级**。默认视图是画面 + 紧凑元数据；`✎ 编辑镜头` 才
   展开表单。未保存缓冲区仍在 shell 的 `ui.buffer` 上，重渲染不丢失，保存
   仍然只追加一个不可变草稿版本。
4. **镜头工作区默认选中一个镜头**（`defaultShotId`）。有生产上下文时中栏
   不留大片空白（规格 §13）；选择失效（草稿重生成 / 切集）时按同一规则回落，
   绝不留悬空选择，且有未保存编辑时不自动改选。
5. **AI 导演的建议必须可由状态证成**。`directorNote` 的每个分支都指向真实
   的缺口或不一致（缺场景地 / 缺参考图 / 未批准大纲 / 未记录首帧…），不对
   它看不见的像素做审美评价。
6. **视频卡片的帧来自该镜头当前图片**，即已记录的首帧；没有记录就如实显示
   「首帧来源未记录」，绝不推断。

## 5. 演示数据（`fixtures/demo-project.js`）

演示模式此前打开即空，媒体优先的界面全部只能渲染空态，无法评审、也无法
截图。本任务加入**仅演示模式**的种子：一个进行到一半的项目
（故事 → 作品设定 → 剧集/场景 → 12 个镜头 → 图片/视频/对白变体 → 时间线）。

- 全部经**领域 API** 写入（proddoc / bibledoc / storydoc / scriptdoc /
  mediaref / genlib），因此不可能与 schema 漂移；
- 媒体是运行时生成的 `data:` SVG 占位图（`fixtures/demo-media.js`），
  **不提交任何二进制**（AGENTS.md §23），每张图上都印着
  「占位素材 · PLACEHOLDER」；
- 进度**故意不均匀**（有的镜头 3 个图片变体、有的 1 个、有的没有；只有前两
  场有视频），空态与半成品态因此仍然可见；
- 连接模式（真实项目）永不触发种子。

**已知取舍（诚实注明）**：占位「视频」「音频」也是 SVG data URI，赋给
`<video src>` / `<audio src>` **无法解码播放**——本机无 ffmpeg，且 §23 不允许
提交生成的媒体二进制。视频 hero 以**已记录的首帧**作 poster，因此静态构图、
变体、血缘全部可评审，只有播放本身在演示种子里不可用；连接模式下是真实文件，
正常播放。
