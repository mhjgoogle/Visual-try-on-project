# 创作者产品信息架构与用户流程（冻结版）

- 依据：[ADR-0066](../adr/ADR-0066-product-refactor-fixed-ia-review-layers-and-system-contract.md)
- 配套：[创作者系统合同](creator-system-contract.md)（对象 / 状态机 / Command / Query / 矩阵）
- 状态：**第一阶段冻结**。本文是创作者界面归属的**唯一权威**；与之冲突的历史描述
  以本文与 ADR-0066 为准。
- 适用范围：`mockups/motv-workspace` 的创作者 Studio。Python 流水线
  （`src/ai_video_workflow/`）的分层与合同不受本文影响。

## 1. 一级导航（封闭集合）

```
┌─────────────────────────────────────────────────────────────────┐
│  ▣ 项目名 ▾            故事开发 │ 剧集制作 │ 资产库        ⚙ 设置 │
└─────────────────────────────────────────────────────────────────┘
```

| 空间 | 一句话 | 对象层级 |
| --- | --- | --- |
| 故事开发 | 把故事写出来 | Project → Outline → 设定 → Episode Plan → Episode Script |
| 剧集制作 | 把这一集做出来 | Episode → Scene → Shot → Artifact |
| 资产库 | 我有什么可以复用 | Asset（跨集、跨阶段） |

- **⚙ 设置**不是第四个空间。它是项目工具面（项目信息 / 成片规格 / 预算与限制 /
  **存储与诊断**），从顶栏项目名旁进入。
- 三个空间之外**不存在**任何一级入口。流程画布、生成溯源、参考统筹、Collections
  都已降级（见 §5 映射表）。

## 2. 二级页面（封闭集合，共十一页）

```
故事开发                        剧集制作                     资产库
 1 项目与创意                    6 本集看板                   11 资产库
 2 故事大纲                      7 分镜设计
 3 作品设定                      8 镜头制作
 4 分集规划                      9 粗剪审片
 5 本集剧本                     10 后期交付
```

**这是封闭集合。** 新增能力落进现有页面；**新增 Skill 不得触发新增页面**。
需要新增页面时，必须先有新 ADR 说明为什么它无法归入现有十一页。

跨空间入口只有一个方向明确的出口：**本集剧本 →「进入剧集制作」**。
落点规则沿用 `shell.episodeEntryModule`，但目标改为：

```
本集尚无分镜草稿  →  分镜设计
本集已有分镜      →  本集看板
```

## 3. 冻结的完整用户流程

```
 1 创建项目
 2 设置成片规格、预算与限制        ⚙ 设置 · 项目
 3 输入故事创意                    ① 项目与创意
 4 生成并确认故事大纲              ② 故事大纲              [用户确认]
 5 建立人物 / 场景 / 道具设定      ③ 作品设定
 6 完成分集规划                    ④ 分集规划              [用户确认]
 7 编写并锁定本集剧本              ⑤ 本集剧本              [用户锁定]
 8 拆分场景和镜头                  ⑦ 分镜设计
 9 完成分镜设计                    ⑦ 分镜设计
10 为镜头绑定参考素材              ⑧ 镜头制作 · 准备输入
11 生成镜头主画面                  ⑧ 镜头制作 · 制作主画面
12 生成视频候选                    ⑧ 镜头制作 · 制作视频
13 单镜头对比与定稿                ⑧ 镜头制作 · 对比候选   [检查层 1 · 用户确认]
14 自动生成整集粗剪                ⑨ 粗剪审片
15 整集粗剪审片                    ⑨ 粗剪审片              [检查层 2 · 用户确认]
16 后期制作                        ⑩ 后期交付
17 交付质检                        ⑩ 后期交付              [检查层 3]
18 导出成片                        ⑩ 后期交付              [用户确认]
```

⑥ 本集看板不在流程线上——它是**状态与入口**，回答「我现在该做哪一步」。
⑪ 资产库不在流程线上——它是**复用面**，被步骤 10 以抽屉形式调用。

### 3.1 三个检查层（互不重叠）

#### 检查层 1 · 单镜头定稿（页面：镜头制作）

- **对象**：同一个 Shot 的多个候选版本。
- **检查**：人物是否对、动作是否对、构图、时长、画面异常（多手 / 变形 / 闪烁 / 穿帮）。
- **动作**：用户选择该镜头的**最终版本**。
- **产出**：该 Shot 的 `confirmed` Artifact Version。
- **不做**：不判断剧情节奏，不判断与相邻镜头的衔接——那是层 2。

#### 检查层 2 · 整集粗剪审片（页面：粗剪审片）

- **前置**：由**已定稿镜头**组成的 Rough Cut 版本。
- **检查**：剧情是否讲清楚、节奏、镜头衔接、连续性、镜头缺失。
- **动作**：标记问题 → **每个问题必须定位到具体镜头** → 退回修改。
- **产出**：Episode 的 `ReviewDecision`（passed / needs_rework）。
- **回环**：镜头修改后**产生新的粗剪版本**并重新审阅。旧版本保留。
- **不做**：不判断音量、字幕、黑帧、编码规格——那是层 3。

#### 检查层 3 · 交付质检（页面：后期交付）

- **对象**：一个 Delivery 候选（导出前的成片）。
- **检查**：音画同步、字幕（存在 / 时序 / 错字）、音量（响度 / 削波）、黑帧、缺帧、
  成片规格（分辨率 / 帧率 / 码率 / 时长 / 容器）、素材权限。
- **分级**：`blocking`（阻断导出）/ `warning`（需用户显式忽略）/ `info`。
- **产出**：Delivery 的 QC Report。
- **它不是创意审片**：发现「这场戏不好看」不属于本层，应回落到层 2。

### 3.2 流程门槛（冻结）

| # | 门槛 | 规则 |
| --- | --- | --- |
| G1 | 测试粗剪 vs 正式审片 | 镜头未全部定稿：可生成**测试粗剪**（标记 `test`），不可提交正式整集审片 |
| G2 | 画面锁定 | 整集粗剪审片 `passed` 后，才可锁定画面剪辑并进入**正式**声音与字幕制作 |
| G3 | 结构变更回退 | 后期修改影响镜头结构（增删镜头 / 换镜头版本 / 改顺序 / 改时长）→ 整集审片状态自动回落为 `needs_rereview`，画面锁定解除 |
| G4 | 阻断导出 | 存在 `blocking` 交付问题时不可正式导出 |
| G5 | 版本非破坏 | 每次粗剪、每次导出**创建新版本**；禁止静默覆盖 |

G3 的判定条件在系统合同文档 §6.3 有精确定义（哪些字段变化算「影响镜头结构」）。

## 4. 页面职责（逐页冻结）

每页给出：目标 · 布局 · 状态 · 主要操作 · Agent 入口 · 跳转规则。
「主要操作」列出的每一项在系统合同文档 §9 的矩阵里都有对应 Command / Query。

### ① 项目与创意

- **目标**：这部作品是什么、要做成什么样、能花多少。
- **布局**：单栏。项目信息卡 / 成片规格卡（形式 · 目标集数 · 单集时长 · 总时长）/
  预算与限制卡 / 创意输入区（长文本 + 版本条）。
- **状态**：`空 / 有草稿 / 已确认`（创意有 active 版本即「已确认」）。
- **主要操作**：编辑创意 · 保存为新版本 · 切换 active 版本 · 编辑成片规格 ·
  设置预算上限与单次生成上限。
- **Agent 入口**：页面级「询问 Agent」（发展创意 / 检查创意是否够拍一集）。
- **跳转**：创意确认 → 「去生成故事大纲」。
- **合并自**：原「创意」页 + 分散在多处的成片规格与预算设置。

### ② 故事大纲

- **目标**：把创意变成有结构的故事大纲。
- **布局**：左=大纲结构（幕 / 章节），右=正文与版本条。
- **状态**：`空 / 草稿 / 已确认 / 已锁定`。
- **主要操作**：生成大纲 · 手工编辑 · 保存新版本 · 切换 active · **确认大纲** ·
  **锁定大纲**（用户确认）。
- **Agent 入口**：页面级「询问 Agent」；段落级「让 Agent 处理」（改写这一段 / 检查结构）。
- **跳转**：大纲确认 → 「去建立作品设定」「去分集规划」。

### ③ 作品设定

- **目标**：人物、场景、道具、关系——**可跨集复用**的作品级设定，以及它们的**基础资产**。
- **布局**：左=对象列表（分区：人物 / 场景 / 道具 / 关系），中=对象档案，
  右=该对象的**基础资产**面板（参考图 / 状态参考 / 基础生图 Prompt / 基础声音）。
- **状态**：每个对象 `草稿 / 完整 / 有缺口`（缺口 = 没有任何参考图，或有状态无参考）。
- **主要操作**：新增 / 编辑 / 删除对象（删除需确认）· 增删对象状态 ·
  上传并登记参考图 · 编辑基础生图 Prompt（版本化）· 上传基础声音 ·
  新增 / 编辑关系 · 调换关系方向。
- **Agent 入口**：对象级「让 Agent 处理」（从剧本补全人物档案 / 提一条关系）。
- **跳转**：从任意镜头的缺口项直接跳到对应对象。
- **合并自**：原「人物」+「世界观」+「人物关系」（ADR-0063 决策 1 / 决策 2 / 决策 3 的
  内容全部在此页内保留，含关系图作为**页内视图**）。
- **约束**：基础资产不新建存储——沿用 `characters[].referenceAssetIds` /
  `states[].overrides` / `promptdoc` 的 `base:` 命名空间 / `voice-reference` 资产
  （ADR-0063 决策 2 的四条硬约束继续有效）。

### ④ 分集规划

- **目标**：把大纲切成集，每集有目标、事件与出场对象。
- **布局**：左=分集列表，中=当前集的规划卡（可手工编辑），右=版本条。
- **状态**：`空 / 草稿 / 已确认`。
- **主要操作**：生成分集规划 · **手工增删改集**（TASK-069 已实施，保留）·
  从大纲播种 Cast（TASK-070，保留）· 确认规划（用户确认）· 设为当前集。
- **Agent 入口**：页面级「询问 Agent」；单集「让 Agent 处理」。
- **跳转**：确认后 → 「去写本集剧本」。

### ⑤ 本集剧本

- **目标**：写出并锁定当前集的剧本。这是故事开发的终点。
- **布局**：单栏正文 + 版本条 + 右侧「本集规划要点」只读参照。
- **状态**：`空 / 草稿 / 已确认 / 已锁定`。
- **主要操作**：生成剧本 · 编辑 · 保存新版本 · 切换 active · **锁定剧本**（用户确认）。
- **Agent 入口**：页面级「询问 Agent」；选中段落「让 Agent 处理」。
- **跳转**：**唯一跨空间出口**「🎬 进入剧集制作 →」，落点见 §2。
- **门槛**：剧本未锁定不阻止进入剧集制作，但分镜设计会显示「上游剧本未锁定」提示；
  剧本锁定后修改需先解锁（用户确认）。

### ⑥ 本集看板

- **目标**：这一集现在什么状况，我下一步做什么。**它是剧集制作的默认落点。**
- **布局**：单栏卡片网格。
- **必须显示**：
  1. 本集阶段（分镜 / 制作 / 审片 / 后期 / 交付）
  2. 各环节完成度（分镜数、已定稿镜头 / 总镜头、粗剪版本、交付状态）
  3. 阻塞问题（缺剧本、缺分镜、缺参考、上游已变化…）
  4. 失败任务（失败的 Skill Run / 生成任务，含失败原因）
  5. 成本状态（本集已花 / 预算 / 剩余）
  6. 待处理镜头（未定稿、有问题标记、被退回的）
  7. 推荐下一步（一到三条，每条带真实动作按钮）
- **硬要求**：**每个异常项都必须能直接跳转到对应对象**（镜头 / 资产 / 任务）。
  一个不能被点开的异常只是抱怨。
- **主要操作**：跳转 · 重试失败任务 · 取消运行中任务。
- **Agent 入口**：页面级「询问 Agent」（本集现在最该做什么）。
- **合并自**：原「本集总览」+ AI 导演右栏的「当前判断 / 缺失项 / 下一步建议」列。

### ⑦ 分镜设计

- **目标**：把剧本拆成场景与镜头，并把每个镜头设计清楚。
- **布局**：**三栏列表，不使用节点图**。
  左=场景列表 · 中=镜头列表 · 右=镜头卡（当前镜头的设计表单）。
- **镜头卡字段（冻结）**：
  1. 镜头描述
  2. 景别 / 角度 / 运镜
  3. 台词与计划时长
  4. 人物 / 场景 / 道具
  5. 参考素材（只读摘要 + 「去镜头制作绑定」）
  6. 首帧要求
  7. 视频要求
- **状态**：镜头 `草稿 / 已设计 / 已进入制作 / 已定稿`。
- **主要操作**：生成分镜草稿 · 新增 / 删除 / 重排镜头（删除需确认）· 编辑镜头卡 ·
  分配镜头到场景 · 应用分镜草稿（覆盖需确认）。
- **Agent 入口**：页面级「询问 Agent」（从剧本拆镜头）；镜头级「让 Agent 处理」
  （补全这一镜的景别 / 运镜 / 时长）。
- **跳转**：镜头 → 镜头制作。
- **合并自**：原「场景」+「分镜」。

### ⑧ 镜头制作

- **目标**：把一个镜头做成**用户选定的最终 Shot Video**。
- **布局**：顶部 = 镜头选择器（场景 ▸ 镜头）+ **四步流程条**；主区 = 当前步骤。

```
① 准备输入  →  ② 制作主画面  →  ③ 制作视频  →  ④ 对比候选并选定
```

| 步 | 内容 |
| --- | --- |
| ① 准备输入 | A/B 两区：**已有可复用基础资产**（来源标注 · 已在用 / 可复用 / 没有）与**当前镜头还需要补充**（`!` 真缺，计入头部数字；`○` 可选）。下方是**可勾选生成清单**，按角色分组，未勾选=推荐。「添加参考」打开资产抽屉。Image Prompt 在此编辑与锁定。 |
| ② 制作主画面 | 发起图片生成 · 候选栅格 · 选定主帧图 |
| ③ 制作视频 | Video Prompt（**硬前置：已选定主帧图**）· 首尾帧绑定 · 发起视频生成 |
| ④ 对比候选 | 并排对比同一镜头的视频候选 · 检查人物 / 动作 / 构图 / 时长 / 画面异常 · **选为最终版本**（用户确认）|
- **必须显示（每个任务）**：状态 · 耗时 · 成本 · 失败原因 · **重试** · **真实取消**。
  「真实取消」= 取消传递到后台任务（ADR-0066 决策 8），不是清空前端状态。
- **状态**：镜头 `未开始 / 准备中 / 主画面制作中 / 视频制作中 / 待定稿 / 已定稿`。
- **Agent 入口**：页面级「询问 Agent」；每步的对象级「让 Agent 处理」
  （推荐资产 / 写 Image Prompt / 写 Video Prompt / 审核 Prompt / 连续性检查）。
- **跳转**：缺口项 → 作品设定对应对象；「生成记录」→ 该结果的溯源详情。
- **合并自**：原「画面」+「视频」+「参考统筹」+「制作台」+ 单镜头审阅（原 dailies 的
  逐镜通过）。**不建立独立审片页面。**

### ⑨ 粗剪审片

- **目标**：把定稿镜头组成整集粗剪，判断这一集**作为一集**成不成立。
- **布局**：上=播放器（整集连播）· 中=镜头条（顺序 · 时长）· 下=问题列表 ·
  右=粗剪版本条。
- **必须支持**：
  1. 自动按剧本与镜头顺序生成粗剪
  2. 整集播放
  3. 镜头顺序与时长调整
  4. 问题标记
  5. **问题定位到镜头**
  6. 退回重新生成 / 更换候选（跳回镜头制作）
  7. 粗剪版本管理
  8. **用户确认整集审片通过**
- **状态**：`无粗剪 / 测试粗剪 / 待审 / 审片通过 / 需要复审 / 需要返工`。
- **门槛**：G1（未全部定稿只能生成测试粗剪）· G3（结构变更 → `需要复审`）。
- **Agent 入口**：页面级「询问 Agent」（连续性 / 节奏检查，输出为**问题列表**，
  永不直接改剪辑）。
- **合并自**：原 dailies 的整集连播 + 原「剪辑」页里的粗剪版本部分。

### ⑩ 后期交付

- **目标**：一个页面内完成从「画面锁定」到「导出成片」的全部后期与交付。
- **布局**：左=分区导航（时间线 / 配音 / 音效音乐 / 字幕 / 预览 / 质检 / 导出），
  中=当前分区，右=版本与导出记录。
- **七个分区（冻结）**：
  1. **时间线与粗剪调整**（clip 顺序 / 入出点 / 转场 / 音量）
  2. **配音**（对白轨 · 本地 TTS · 按镜头对齐）
  3. **环境音、音效与音乐**（ambience / sfx / foley / BGM）
  4. **字幕**（从对白与时序生成；无 ASR 时显示 not available，绝不伪造听写）
  5. **成片预览**
  6. **交付质检**（检查层 3）
  7. **导出及导出记录**
- **状态**：`画面未锁定 / 制作中 / 待质检 / 可导出 / 存在阻断问题 / 已导出`。
- **主要操作**：锁定画面（用户确认）· 生成配音 · 自动混音 · 生成字幕 ·
  运行质检 · 忽略非阻断问题（用户确认）· **导出**（用户确认）。
- **明确不做**：不是 Premiere / DaVinci 的替代品。不包含复杂节点、专业调色、
  多机位、插件系统、无限轨道。
- **Agent 入口**：页面级「询问 Agent」；分区级「让 Agent 处理」（提音效事件 / 校字幕）。
- **合并自**：原「音频」+「剪辑」+ 后期控制台 dock。

### ⑪ 资产库

- **目标**：我有什么可以复用。**一个页面，条件筛选。**
- **布局**：顶=筛选条，下=网格 / 列表，右=选中资产的详情与用法。
- **筛选维度（冻结）**：
  - 对象类：人物 / 场景 / 道具
  - 媒体类：图片 / 视频 / 音频 / 成片 / 参考
  - 范围：全项目 / 本集 / 本镜
  - 状态：可用 / 已归档 / 媒体缺失
  - 已保存筛选（原 Collections）
- **主要操作**：上传并登记资产 · 编辑元数据 · 归档 / 取消归档 ·
  删除（双重确认）· 保存筛选 · 「在哪被用」反查。
- **Agent 入口**：页面级「询问 Agent」（找一张符合描述的参考）。
- **合并自**：原七个 `assets:*` 工作区（全部降级为预置筛选）。
- **抽屉形态**：镜头制作的「添加参考」打开的是**同一个组件**的抽屉模式。
  一份实现，两个触发点。

### ⚙ 项目设置（工具面，不计入十一页）

- **项目**：名称 · 根目录 · 成片规格 · 预算与限制。
- **存储与诊断**：存储生命周期管理（归档 / 移除字节 / 永久删除，保留原有双重确认）·
  运行时探测状态 · schema 版本 · **诊断视图**（整集生成溯源图 / 流程画布，
  `?canvas=1` 保留）。
- 这些界面**不出现在三空间导航里**，也不是生产路径的一部分。

## 5. 现状 → 目标 映射表（保留 / 合并 / 降级 / 隐藏 / 删除）

处理方式定义：

- **保留**：仍是一个二级页面（可能改名）。
- **合并**：并入另一个页面，作为其分区 / 步骤 / 页签。
- **降级**：能力保留，但不再是导航项（变成抽屉 / 面板 / 记录 / 筛选 / 诊断）。
- **隐藏**：代码保留、路径保留，普通用户主路径上不可见。
- **删除**：入口删除（能力已由别处覆盖）。

## 6. Agent 协作方式（冻结）

### 6.1 统一交互流程

```
用户表达意图（在某个页面 / 某个对象上）
   ↓
Agent 读取当前页面与对象上下文        shotctx / 页面级投影，最小必要
   ↓
检查输入完整性
   ↓
只询问缺失信息                        不重复问已经在文档里的东西
   ↓
按能力声明选择 Skill                  用户不选 Skill ID
   ↓
展示：任务理解 · 输入 · 产物 · 影响 · 成本 · 耗时
   ↓
必要时用户确认                        → SkillRun.status = awaiting_confirmation
   ↓
创建持久化 Skill Run                  → queued → running
   ↓
返回建议或候选                        → succeeded，proposal.disposition = pending
   ↓
用户接受 / 修改 / 重新生成
   ↓
用户确认为正式版本                    → ArtifactVersion.state = confirmed
```

### 6.2 入口只有两类

| 入口 | 位置 | 上下文 |
| --- | --- | --- |
| 页面级「询问 Agent」 | 每个页面的固定位置（顶部右侧） | 当前页面 + 当前主对象（集 / 镜头 / 资产） |
| 对象级「让 Agent 处理」 | 每个可操作对象的卡片 / 行上 | 该对象 + 其上游 |

**没有第三类入口。** 没有常驻聊天侧栏，没有全局悬浮球，没有每个字段旁的魔法棒。

### 6.3 Agent 面板只展示七项

```
1 当前发现的问题          来自真实数据的检查，不是模型的印象
2 Agent 对任务的理解      任务名称 + 它读到了什么
3 缺失输入                逐项可点，点到能修它的地方
4 推荐下一步              一到三条
5 一个主要执行按钮        主动作唯一
6 查看其他方案            折叠，不与主动作竞争
7 执行后的候选结果与版本差异
```

不展示：Skill ID · Skill 版本 · Runtime · Executor · Provider · Model ·
内部任务 ID · context snapshot。这些**全部**进入结果旁的「生成记录」。
普通用户看到的是**任务名称**（如「为这一镜写画面提示词」）。

### 6.4 不可用就说不可用

- runtime 不可用 / 必要输入缺失 / 输出不符合契约 → 显示 `unavailable` 并说明原因，
  **不显示成一个会假装工作的按钮**（ADR-0064 决策 6，继续有效）。
- 每个 AI 动作都必须有**手工兜底**：复制任务 Prompt → 外部跑 → 粘回 → 走同一道
  输出契约与确认门（ADR-0065 决策 2，继续有效）。

## 7. 用户与 Agent 的权限边界（冻结）

### 7.1 Agent 可以自动执行

| # | 动作 | 说明 |
| --- | --- | --- |
| A1 | 分析现有输入 | 读投影，不写 |
| A2 | 检查缺失与冲突 | 产出问题列表 |
| A3 | 生成草稿 | 落到 `draft`，不进 active |
| A4 | 生成建议 | 落到 `suggested` |
| A5 | 生成候选 | 落到 `candidate`，**不改 active 指针** |
| A6 | 执行不产生外部费用的检查 | 本地 / 订阅内 |
| A7 | 标记质量问题 | 产出 `ReviewIssue`，不产出 `ReviewDecision` |

A3–A5 若会消耗**付费**能力，则不属于此列——落入 U5。

### 7.2 必须由用户确认

| # | 动作 | 确认形式 |
| --- | --- | --- |
| U1 | 锁定大纲或剧本 | 显式按钮 |
| U2 | 覆盖用户修改过的内容 | 二次确认 + 差异预览 |
| U3 | 删除镜头或资产 | 二次确认（资产删字节为双重确认，沿用现状） |
| U4 | 修改正式绑定关系 | 显式按钮 |
| U5 | 使用付费生成能力 | 显式确认 + **金额预览**（沿用 ADR-0046 批量总额确认） |
| U6 | 批量重新生成 | 显式确认 + 影响范围与总额预览 |
| U7 | 将候选设为最终版本 | 显式按钮 |
| U8 | 通过单镜头定稿 | 显式按钮（检查层 1） |
| U9 | 通过整集审片 | 显式按钮（检查层 2） |
| U10 | 忽略非阻断质量问题 | 显式按钮 + 记录到 QC Report |
| U11 | 锁定粗剪 | 显式按钮 |
| U12 | 导出或发布成片 | 显式按钮 |

### 7.3 四条禁令

**Agent 不得静默覆盖 · 不得静默定稿 · 不得静默付费 · 不得替用户完成审美决策。**

这四条在系统层的执行方式（不是 UI 层的约定）见系统合同文档 §5.3：
`actions.allowedAt` 在 `CURRENT_LEVEL = "suggest"` 下拒绝一切 AI origin 的写动作，
Command Gateway 对高风险 Command 要求 `confirmation`。
